# A Bit More About Me

I'm a software engineer building **AI-based solutions** for **law** and **investments**. I like **teaching machines** to help people reach better **results**, and I care about measuring that they actually do.

I work as a **Generative AI Engineer**, with previous experience as an **AI/ML Engineer** (technical lead on a legal-tech team), a **trainee AI Developer** at **Compass.UOL**, and hands-on work as a **Data Engineer**. My projects revolve around **LLM-based applications and agents**: **RAG and graph-RAG** knowledge bases, **LLMOps and evaluation** (LLM-as-judge, regression baselines), **MCP servers**, and the **data pipelines** that feed them.

I hold a **Systems Analysis and Development** degree (SENAC-PE), an **MBA in Data Science and Artificial Intelligence** (SENAC-PE) and a **law degree**, with some experience as a lawyer, which fuels my interest in AI for legal problems.

### What I'm Building Now

- [**juris-bridge-mcp**](https://github.com/emvalencaf/juris-bridge-mcp): remote MCP server giving AI agents access to Brazilian judicial data.
- [**legal-radar**](https://github.com/emvalencaf/legal-radar): graph-RAG over Brazilian law, with citations traceable to the graph.
- [**assayer**](https://github.com/emvalencaf/assayer): Python library for evaluating and observing LLM applications.
- [**extraction-llm-pipeline**](https://github.com/emvalencaf/extraction-llm-pipeline): invoice PDFs to validated JSON with an LLM on AWS, gated by a regression baseline.
- [**capitol-lake**](https://github.com/emvalencaf/capitol-lake): Congress stock-trading disclosures as a queryable dataset.
- [**literature-notes**](https://github.com/emvalencaf/literature-notes): agent skills that turn academic sources into an LLM wiki of reading notes.
